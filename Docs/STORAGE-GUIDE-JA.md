# Sakura Storage Center — クイックガイド

1. microSDカードを取り外す前に、Nintendo Switchの電源を完全に切ってください。
2. microSDカードは専用カードリーダーでMacに接続してください。Switch本体のUSB接続（DBI/MTP）はStorage Centerのカードリーダーの代わりにはなりません。
3. 「解析」はメタデータの読み取りのみです。「バックアップ」はカード上のアクセス可能なファイルをMacに保存し、「復元」は選択したカードにデータを書き込みます。
4. コピー・SHA-256検証・復元中にカードを取り外さないでください。
5. ファイル単位のバックアップにはアクセス可能なファイル（ファイル型emuMMCを含む）が入りますが、**隠しRAW emuMMCパーティション**やディスク全体の完全なイメージは含まれません。
6. 復元前に書き込み先のカードを必ず確認してください。データが変更される場合があります。
