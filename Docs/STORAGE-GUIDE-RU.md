# Sakura Storage Center — краткая инструкция

1. Полностью выключите Nintendo Switch перед извлечением microSD.
2. Подключите microSD к Mac через отдельный кардридер. Подключение Nintendo Switch через USB, DBI или MTP не заменяет кардридер для Storage Center.
3. «Анализ» только читает метаданные. «Копия» сохраняет файлы карты на Mac. «Восстановить» записывает данные на выбранную карту.
4. Не отключайте накопитель во время копирования, проверки SHA-256 или восстановления.
5. Файловая резервная копия включает доступные файлы (в том числе файловую emuMMC), но **не** скрытую RAW-разметку/RAW-раздел emuMMC и не является побитовым образом карты.
6. Перед восстановлением убедитесь, что выбрали правильную целевую карту: запись может изменить её содержимое.
