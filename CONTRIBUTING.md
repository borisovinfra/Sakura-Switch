# 🌸 Вклад в Sakura Switch

Спасибо за интерес к развитию Sakura Switch.

## Сообщения об ошибках

Для ошибок используйте шаблон **🐛 Сообщить об ошибке** в разделе Issues.

Перед созданием нового сообщения проверьте, не сообщал ли уже кто-нибудь об этой проблеме.

## Предложения

Новые идеи и улучшения можно предложить через шаблон **✨ Предложить функцию**.

## Изменения кода

Если вы хотите предложить изменение исходного кода:

1. Создайте fork репозитория.
2. Создайте отдельную ветку для изменения.
3. Внесите изменения и проверьте сборку.
4. Создайте Pull Request с кратким описанием изменений.

Пожалуйста, не включайте в Pull Request игры, прошивки, ключи шифрования или другой защищённый авторским правом контент.

## Требования

- macOS 15.0+
- Swift 6
- Изменения должны сохранять нативный подход Sakura Switch.
- Код должен быть понятным и не содержать ненужных зависимостей.

## Лицензирование вкладов

Отправляя Pull Request в Sakura Switch, вы подтверждаете, что имеете право предоставить предлагаемый код и другие материалы проекту.

Если явно не указано иное, любой принятый вклад предоставляется на условиях лицензии, применяемой к Sakura Switch, и может быть включён в проект, изменён и распространяться в соответствии с этими условиями.

Отправка Pull Request не передаёт авторство вашего вклада Project Sakura или Amir Borisov. Вы сохраняете авторские права на созданный вами код.

Если для будущего использования конкретного вклада потребуются дополнительные права или отдельное разрешение, они должны быть согласованы с автором такого вклада отдельно.
